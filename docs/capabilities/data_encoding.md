# data_encoding

What it does: Compresses bytes, decompresses them, and checks integrity.

Algorithm design:
- Compress input bytes with `zlib`.
- Decompress and verify round-trip equality.
- Hash original content with `sha256`.

Why this design:
- Keeps correctness checks very clear.
- Compression ratio + hash gives easy quality signals.

Input: Generated byte payload.

Output: `input_bytes`, `compressed_bytes`, `ratio`, `roundtrip`, `sha256`.

## Usage Example


```python
from chuck.tasks.data_encoding.task import generate, solve


sample_data = generate(size=1000, seed=42)
print(f"Generated {len(sample_data)} bytes of data.")


result = solve(payload=sample_data)


print("Encoding Results:")
print(f"Original Size: {result['input_bytes']} bytes")
print(f"Compressed Size: {result['compressed_bytes']} bytes")
print(f"Compression Ratio: {result['ratio']}")
print(f"Roundtrip Successful: {result['roundtrip']}")
print(f"Data SHA256: {result['sha256']}")
