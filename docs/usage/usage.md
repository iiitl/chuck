# Usage Guide

This document demonstrates how to use the task with a simple example.

---

##  Overview

The task performs a basic operation where it takes input values, processes them, and returns the result.

---

##  Example Code

```python
def add(a, b):
    return a + b

# Example usage
a = 2
b = 3

result = add(a, b)
print("Result:", result)
```

---

##  Input

```
a = 2
b = 3
```

---

##  Output

```
Result: 5
```

---

##  Explanation

* The function `add(a, b)` takes two numbers as input.
* It returns the sum of those numbers.
* In this example:

  * `a = 2`
  * `b = 3`
* The output is `5`.

---

##  How to Run

1. Make sure Python is installed.
2. Save the code in a file named `example.py`.
3. Run the following command in your terminal:

```
python example.py
```

---

## ✅ Expected Result

You should see:

```
Result: 5
```

## 📎 Notes

* You can change the input values (`a` and `b`) to test different results.
